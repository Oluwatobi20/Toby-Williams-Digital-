# Toby Williams Digital — Digital Marketing Portfolio

**A live, music-first digital marketing website demonstrating website development, search optimisation, conversion-focused design and digital campaign strategy.**

[**View the live website**](https://tobywilliamsdigital.co.uk) · [**Explore music marketing services**](https://tobywilliamsdigital.co.uk/music-marketing.html) · [**Contact / enquiry page**](https://tobywilliamsdigital.co.uk/contact.html)

## About the project

Toby Williams Digital is a UK-based, music-first digital marketing business serving independent artists, bands and music businesses, while also welcoming clients from other sectors.

This repository contains the source files for its multi-page marketing website. The project brings together **marketing strategy and practical web implementation**: explaining services clearly, guiding visitors towards an enquiry or consultation, and establishing a foundation for organic search and analytics.

**Portfolio context:** This is a live business website and practical demonstration of marketing and website skills. Illustrative case studies or mock-ups on the site are labelled as examples; they are not presented as verified client outcomes.

## Skills demonstrated

| Skill | How it is demonstrated |
| --- | --- |
| **Digital marketing strategy** | Audience-specific messaging, music-industry positioning, service packages and calls to action |
| **Website design and development** | Responsive multi-page site built with HTML, CSS and JavaScript |
| **Search engine optimisation (SEO)** | Page-specific titles and descriptions, search-friendly content and indexing considerations |
| **Conversion rate optimisation (CRO)** | Clear service journeys, contact form, consultation booking links and thank-you page |
| **Google Analytics 4 (GA4)** | Consent-aware analytics implementation and lead/conversion measurement groundwork |

## Website features

- Music marketing and broader digital marketing service pages
- Responsive, dark-themed design for desktop and mobile
- Service packages and transparent starting-price information
- Netlify-compatible enquiry form and thank-you page
- Calendly consultation booking link
- Consent-aware Google Analytics 4 integration
- Search-focused page titles, descriptions and content
- Clearly labelled illustrative examples rather than fabricated client testimonials

## Technology and tools

**Website:** HTML, CSS, JavaScript  
**Hosting/deployment:** Netlify  
**Version control:** Git and GitHub  
**Analytics:** Google Analytics 4  
**Search:** Google Search Console  
**Bookings:** Calendly  
**Testing:** GitHub Actions and Playwright-based browser checks
